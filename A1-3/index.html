FAQ

추천 데이터는 어디서 가져오나요?

여행지 추천과 일정은 AI(OpenAI)가 생성하고, 맛집 정보는 카카오 로컬(Kakao Local) 검색 결과를 사용합니다.

추천 결과가 실제와 다를 수 있나요?

네. AI가 생성한 날씨·행사 정보는 일반적인 경향을 바탕으로 한 참고용이며, 실제 예보나 행사 일정은 여행 전 별도로 확인하는 것이 좋습니다.

같은 날짜로 다시 검색하면 어떻게 되나요?

브라우저에 저장된 이전 추천 결과를 재사용해 더 빠르게 결과를 보여드려요. 다른 추천을 받고 싶다면 "새로 추천받기" 버튼을 눌러주세요.

맛집 정보가 없다고 나와요.

카카오 로컬 검색 결과가 없거나 일시적인 오류가 발생한 경우 해당 지역만 "데이터 없음"으로 표시되며, 다른 지역과 리포트는 정상적으로 생성됩니다.
