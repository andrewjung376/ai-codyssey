# 서비스 기획서: AI여행추천 (AI TripPick)

## 1. 서비스 개요

- **서비스명**: AI여행추천 (영문: AI TripPick)
- **목적**: 여행 날짜를 입력하면 AI가 그 시기에 맞는 국내 여행지 2~3곳을 추천하고, 실제 맛집 데이터와 1일 일정을 한 화면에서 보여준다.
- **타겟 사용자**: 여행 날짜는 정했지만 행선지를 못 정한 20~40대 직장인
- **제공 가치**: 검색 시간 단축, 시기(날씨·축제)에 맞는 추천, 지도 링크가 있는 실제 맛집 데이터

## 2. 페이지/섹션 구성

단일 페이지(`index.html`) 안에서 4개 섹션을 해시 링크로 이동한다. 모바일에서는 햄버거 메뉴를 사용한다.

| 섹션 | 내용 |
|---|---|
| 홈(Hero) | 서비스 소개와 "여행지 추천받기" 버튼 |
| 이용 방법 | 추천 → 맛집 → 일정, 3단계 흐름 설명 |
| AI 플래너 | 날짜/취향 입력 폼과 추천 결과(지역 카드, 맛집, 일정) |
| FAQ | 데이터 출처, 정확도 한계, 재추천 방법 안내 |

## 3. 핵심 기능

1. 날짜 기반 여행지 추천 (AI)
2. 지역별 실제 맛집 검색 (Kakao Local API)
3. 지역별 1일 일정 제안 (AI)
4. 결과 캐싱 (동일 날짜 재조회 시 API 재호출 없이 즉시 표시)

## 4. AI 기능 상세 (입력/출력/실패 처리)

### 입력
- 여행 날짜 (필수, `YYYY-MM-DD`, 오늘 이후)
- 여행 취향 (선택, 최대 200자, 예: "부모님과, 걷기 적은 일정")

### 출력
- 추천 지역 2~3곳: 지역명, 날씨 요약, 행사/축제, 추천 이유
- 지역별 맛집 최대 5곳: 이름, 주소, 카테고리, 지도 링크
- 지역별 1일 일정: 오전/오후/저녁 제안
- 리포트 Markdown 다운로드

### 실패 처리 기준

| 상황 | 사용자에게 제공하는 안내 |
|---|---|
| 빈 입력 / 날짜 형식 오류 | 입력 필드 옆에 "여행 날짜를 선택해 주세요" 등 즉시 안내 |
| API 오류(4xx/5xx) | "AI 응답을 받지 못했어요. 잠시 후 다시 시도해 주세요" + 재시도 버튼 |
| 응답 지연/타임아웃 | 8초 경과 시 지연 안내, 30초 경과 시 요청 중단 및 재시도 안내 |
| 일부 데이터 없음 (예: 맛집 검색 결과 0건) | 서비스 중단 없이 해당 항목만 "데이터 없음"으로 표시하고 나머지는 계속 진행 |

## 5. 기술 스택

- **프론트엔드**: 순수 HTML / CSS / JavaScript (프레임워크 미사용)
- **백엔드**: Vercel Serverless Functions (Python)
- **AI API**: OpenAI (여행지 추천, 일정 생성)
- **외부 API**: Kakao Local API (맛집 검색)
- **배포**: Vercel
